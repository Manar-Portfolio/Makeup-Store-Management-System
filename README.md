# Makeup Store Management System

A C++ academic group project developed for the Data Structures course using a singly linked list.

## Features
- Add and search for products by ID.
- Update product prices and quantities.
- Delete products by ID.
- Display product details, including prices with and without tax.

## Technical Concepts
- Singly Linked List
- Object-Oriented Programming (OOP)
- Dynamic Memory Allocation
